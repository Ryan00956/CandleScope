# 繁體中文（台灣）術語表

本表在翻譯 `zh-TW` 主詞典與內建外掛文案之前鎖定用語。目標讀者是台灣的加密貨幣／合約看盤使用者，同時讓證券期貨背景的用語也能被自然理解。

- Locale：`zh-TW`
- 別名：僅 `zh-Hant-TW`。`zh-HK`、`zh-MO`、未限定的 `zh-Hant` 不映射到 `zh-TW`。
- 狀態：**ENGINEERING_LOCKED / NATIVE_REVIEW_REQUIRED**
- 初稿方法：OpenCC `s2twp`（簡體 → 台灣用語）產生草稿，再依本表覆寫。機械轉換與 AI 翻譯均不視為母語覆核。

## 不可翻譯的技術原文

以下保持原文，不進入簡繁轉換或本地化替換：

- 產品名：`CandleScope`
- 交易對：`BTCUSDT` 等
- 週期 ID：`1m`、`4h`、`1d` 等
- 交易所／品牌：`Binance`、`OKX`、`TradingView` 等需保留的品牌名
- 協議值：`BAR`、`AGG_TRADE`、`BOOK_ASSISTED_REQUIRED`、`HEDGE_HYBRID`、`ONE_WAY`、`SANDBOX_FIXED` 等
- API 方法名、錯誤碼、檔名、原始第三方診斷

插值變數（`{count}`、`{symbol}`、`{exchange}`、`{interval}`、`{value}`、`{hours}`、`{permission}` 等）必須原樣保留。

## 交易與看盤用語

規則：同一概念在主程式、外掛、錯誤、Tooltip 與測試中使用同一譯名。不把證券官方用語強行套到加密貨幣介面，也不把中國大陸交易所用詞原樣搬進台灣介面。

### 訂單／委託

| 概念 | 採用 | 規則 |
| --- | --- | --- |
| 訂單物件、訂單列表、未成交單 | 訂單 | 對應英文 *order*。加密貨幣看盤與幣安／OKX 台灣介面通用「訂單」。 |
| 下單、委託行為 | 委託 | 對應來源文案的「委托」。 |
| 委託單 | 委託單 | 僅在來源明確指「一張委託單」時使用，不把所有「訂單」改成「委託單」。 |
| 撤單 | 撤單 | 取消未成交委託。 |
| 成交 | 成交 | 已撮合。 |
| 未成交 | 未成交 | 仍在簿上的訂單。 |

**爭議與選擇：** 台灣證券慣用「委託／委託單／委託簿」，加密貨幣產品慣用「訂單／訂單簿」。CandleScope 是加密貨幣看盤軟體，來源詞典已區分「盘口／订单簿／委托」。決定：**保留來源區分**，字面轉為繁體，不把「訂單」統一改成「委託單」。

### 倉位／持倉／部位

| 概念 | 採用 | 規則 |
| --- | --- | --- |
| 倉位 | 倉位 | 部位大小、方向、繪圖上的 position size。 |
| 持倉 | 持倉 | 目前持有狀態（持倉模式、持倉列表）。 |
| 持倉量 | 持倉量 | open interest 或持倉數量，依來源鍵語意。 |
| 部位 | 部位 | 僅當來源使用「部位」時保留。不把「倉位」自動改成「部位」。 |

**爭議與選擇：** 台灣期貨官方用語是「部位」。Binance／OKX 等加密貨幣繁中介面使用「倉位／持倉」。決定：跟加密貨幣產品，不用「部位」替換「倉位」。

## 標點與用字

- 使用繁體漢字；不用簡體字。
- 台灣用「裡」「為」，不用「裏」「爲」，除非技術原文。
- 省略號沿用來源的 `…` 或 `...`，不改成全形 `……` 以免排版迴歸。
- 不把技術原文裡的簡體字（若作為協議／檔名出現）改掉，檢查器也不得誤報。
